# Dizajn ATENA

Cieľ: najkrajší a najpríťažlivejší dizajn – vychádza zo ŠkVP (Windows 11 / Fluent), ktorý sa autorovi páči,
a ide ďalej. Ukážka: plátno „ATENA – ukážka dizajnu“ (prehľad dňa svetlý a tmavý, stránka metódy, mobil).

## Zásady
1. **Pokojné pastelové farby**, nič sýte, čo unavuje oči; vyšší kontrast textu (WCAG 2.2 AA).
2. **Väčšie písmo**: základ 15–16 px, nadpisy 30–34 px.
3. **Svetlý a tmavý vzhľad** aj „podľa systému“; prepnutie okamžité.
4. **Každá sekcia má svoju farbu** (ako vzdelávacie oblasti v ŠkVP) – pásik v menu, pruh na karte, štítok pri položke.
5. **Karty** so zaoblením 10 px, jemný okraj, pri prechode myšou sa nadvihnú; žiadne gradienty na plochách.
6. **Ľavé menu** s ikonami, modrý pásik pri vybranej položke, vnorené položky s farebným pásikom; zbalené na úzky pás ikon.
7. **Mobil**: menu dole na dosah palca, ciele dotyku ≥ 44 px.
8. **Poctivosť v rozhraní**: autorita zdroja (A1 – D) pri každej položke, „preklad – návrh“, „návrh ATENA“, originál vždy na jeden klik.

## Písmo
`'Segoe UI Variable Text', 'Segoe UI', 'Open Sans', system-ui` – vo Windows Segoe UI ako ŠkVP,
inde Open Sans (OFL, rovnaký autor ako Segoe UI). Nadpisy `Segoe UI Variable Display`.

## Ikony
Fluent UI System Icons (Microsoft, MIT) – rovnaký štýl ako Windows 11 a ŠkVP; v ukážke zatiaľ vlastné čiarové ikony.
